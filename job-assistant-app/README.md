# Job Assistant App

## Overview
The Job Assistant App is a Python application designed to help users streamline their job application process. It provides features for analyzing resumes, matching job descriptions, and generating tailored cover letters. The application utilizes various machine learning techniques and natural language processing to enhance the job application experience.

## Installation Instructions
To set up the project environment, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   cd job-assistant-app
   ```

2. Create a virtual environment:
   ```
   python -m venv venv
   ```

3. Activate the virtual environment:
   - On Windows:
     ```
     venv\Scripts\activate
     ```
   - On macOS/Linux:
     ```
     source venv/bin/activate
     ```

4. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage
To run the application, execute the following command:
```
python src/app.py
```

## Testing
To run the tests, ensure that the virtual environment is activated and execute:
```
pytest tests/test_app.py
```
